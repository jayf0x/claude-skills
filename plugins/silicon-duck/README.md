# silicon-duck

Always-on rubber duck that rates the clarity of the conversation before every reply — a three-factor **CIP score** (Constraints / Intent / Provenance, 1–5) so you can see at a glance how well-specified your prompt is.

## Install

```bash
./plugins/silicon-duck/install.sh
```

Restart Claude Code. Active by default from then on — no setup needed.

## Use

```
/duck disable   # silence it
/duck enable    # bring it back
```

## Uninstall

```bash
./plugins/silicon-duck/uninstall.sh
```
